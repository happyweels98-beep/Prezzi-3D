INSTALLAZIONE SU IPHONE
L'app deve essere pubblicata su un indirizzo HTTPS per poter essere installata correttamente. Un file aperto localmente o l'anteprima in chat non è sufficiente.

Procedura generale gratuita con GitHub Pages:
1. Crea/accedi a un account GitHub.
2. Crea un nuovo repository pubblico, ad esempio prezzi-3d.
3. Carica tutti i file contenuti in questa cartella nella radice del repository.
4. In Settings > Pages, scegli la pubblicazione dal branch principale (root) e salva.
5. Quando GitHub mostra l'indirizzo HTTPS del sito, aprilo in Safari su iPhone.
6. Premi Condividi > Aggiungi alla schermata Home.

I nomi delle voci GitHub possono cambiare leggermente. I prodotti salvati restano sul browser/dispositivo: non sono sincronizzati automaticamente tra dispositivi.
